### The paper (T2, 50 marks)

| Section | Marks | What came in the non-internship paper (27 Oct 2026) |
|---|---|---|
| Q1 MCQs (CO1–CO2) | 6 | CRC polynomial, pure ALOHA bandwidth, latency, transmission time, mesh links, invalid MAC |
| Q2 MCQs (CO3–CO4) | 14 | TDM rate, sync TDM efficiency, SSL, window scale, UDP header size, P2P/client-server, DNS TTL, ping sweep, traceroute, Wireshark filters, routing table, shortest path tree, Dijkstra |
| Q3 theory | 5 | HTTP message types (2), TCP header format (3) |
| Q4 numericals | 25 | Jio block allocation (4), DV routing (4), multi-link fragmentation (3), sliding window rate (3), link state (3), UDP dump (3), TCP Reno (3), datagram count (2) |

### Order to attempt

1. **MCQs first** (about 15 minutes). Every Units 5–10 MCQ is from the practice book. Options are shuffled into 8 choices, so match the **text**.
2. **Quick numericals**: UDP dump, datagram count, sliding window rate, Reno. These are 2–3 minutes each.
3. **Medium numericals**: fragmentation, block allocation.
4. **Graph sums last**: Dijkstra and distance vector take longest. Draw the table even if you run short of time; the method earns marks.
5. **Theory** if time is left: the HTTP request/response layout and the TCP header diagram are in the guides.

### Writing numericals for marks

- Write **Given**, then the formula, then the substitution, then the answer with units.
- Draw tables for fragmentation, subnets and routing. Examiners mark the steps.
- Box the final answer.
- If you are stuck, write the method in words. Partial marks are real.

### Passing maths

You need **20 / 50**. Fourteen practice-book MCQs plus three or four of the six T1 MCQs is about 17. Two quick numericals (UDP dump 3, datagram count 2) plus one table sum (3–4) takes you past 25.
